# sampling-calc（抜取検査計算機）

計数値の一回抜取検査を計算する Web アプリ。ブラウザだけで動き、入力したデータは外部に送信しない。

## 機能

| タブ | 入力 | 出力 |
|---|---|---|
| 合格率 | ロットサイズ、不良率または不良数、抜き取り数 n、c | 合格確率、抜取中の不良数の分布、100ロット流した場合の合格数・流出不良、n や不良率を変えたときの変化 |
| AQL方式 | ロットサイズ、検査水準、AQL、なみ／きつい／ゆるい | n・Ac・Re、サンプル文字（矢印処理込み）、OC曲線、Pa=95/50/10 % の品質 |
| OC曲線・比較 | 最大3方式の N・n・c、分布 | OC・AOQ・ATI 曲線、AOQL、CSV・PNG 出力 |
| 逆設計 | p₁・α・p₂・β、N（任意） | 条件を満たす最小の n・c、c=0 方式との比較 |
| 不良率推定 | 検査数 n、不良数 x、信頼度、N（任意） | Clopper-Pearson 法の上限・区間、ロット内不良数の上限 |

条件は URL のクエリに保存されるので、アドレスをそのまま共有すれば同じ計算を再現できる。

## PWA（オフライン・ホーム画面への追加）

GitHub Pages など HTTPS で公開すると PWA として動く。初回表示で必要なファイルを端末に保存するので、2回目以降は通信なしで開ける。

- Android（Chrome）: メニューの「アプリをインストール」または「ホーム画面に追加」
- iPhone（Safari）: 共有 →「ホーム画面に追加」
- Windows（Chrome / Edge）: アドレスバー右端のインストールボタン

**更新時の手順**: `index.html`・`js/`・アイコンを変更して公開するときは、`sw.js` 先頭の `VERSION` を必ず上げる。上げないと、利用者の端末に古いファイルが残り続ける。新しい版は次回起動時に取り込まれ、その次に開いたときに反映される。

ファイルを直接開いた場合（file://）は Service Worker が動かないので、PWA にはならない（計算は普通に動く）。

## 計算の前提

- 分布は「自動」で n/N > 0.1 のとき超幾何、それ以外は二項。AQL が 10 を超える場合は 100 単位当たり欠点数としてポアソン分布で計算する
- AOQ・ATI は「不合格ロットを全数選別し、不良品を良品に置き換える」前提
- 超幾何分布の OC 曲線は、ロット内不良数 D = p·N が整数でない点を前後の整数で線形補間している

## AQL 表のデータ

- 出典: MIL-STD-105E（1989-05-10）表I・表II-A/B/C。DTIC ADA284013、Distribution Statement A（配布制限なし）
- `js/aql-table.js` に矢印を解決済みの [n, Ac, Re] で格納
- なみ検査は、対角構造（サンプル文字の行番号 + AQL の列番号で Ac/Re が決まる）から独立に組んだ表と全 416 セルを照合して一致を確認済み。きつい・ゆるい検査は R パッケージ AQLSchemes 1.7-2 の値を使用
- JIS Z 9015-1:2006（ISO 2859-1:1999）とは、ゆるい検査の方式（105E は Ac と Re の間に差がある）と切替ルールが異なる。なみ・きつい検査の表を JIS として扱う場合は JIS 本文と照合すること

## テスト

`tests/test.html` をブラウザで開くと、計算ライブラリを scipy の参照値と、AQL 表を既知の値と照合する。
参照値は `tests/make_reference.py`（scipy が必要）で再生成できる。

## 構成

```
index.html          画面
manifest.webmanifest  PWA のマニフェスト
sw.js               Service Worker（オフライン用キャッシュ）
icons/              アプリアイコン
js/app.js           画面処理・グラフ描画
js/stats.js         統計計算（依存なし、Node でも読み込み可）
js/aql-table.js     MIL-STD-105E 表データ
tests/              照合用テスト
```
